# Academic Homepage (Pure HTML/CSS/JS)

A lightweight academic homepage template designed for GitHub Pages.
No build tools, no Jekyll, no Node — just edit a few files and push.

## Quick start (GitHub Pages)

1. Create a repo named: **<your-username>.github.io**
2. Upload all files in this folder to the repo root.
3. GitHub → Settings → Pages → Deploy from branch (main / root)
4. Visit: https://<your-username>.github.io

## Customize

- `index.html`: your name, affiliation, links, section text
- `assets/avatar.jpg`: replace with your portrait (keep name)
- `assets/CV.pdf`: optional
- `data/news.json`: news items
- `data/publications.json`: publication list
- `data/projects.json`: projects

## Tips

- Put PDFs and slides under `assets/` or `papers/` and link them in JSON.
- For Google Scholar, put your profile URL in the sidebar.
